# L1 · The text

**Goal.** Settle what the text *is* before anyone reads it: the unit of writing (glyph
segmentation), where transcriptions disagree, page order, scribes.

**What counts.**
- *Segmentation* (experiment kind `segmentation`, `"units": [...]`): a list of multi-character
  glyphs. Scored as held-out bits per EVA character under a pinned character model; it counts
  if it beats `eva-basic`. Tools: `vs/ivtff.py` (SEGMENTATIONS, segment), `vs/experiment.py`
  (segmentation_score).
- *Facts about the text* (kind `fact`, see L2) on scribes, page order or quires.
- *Data* PRs (reviewed): a consensus file of ZL 3b vs the Landini-Stolfi interlinear, both pinned.

**Publicly known (cite, don't re-derive).** EVA is a transcription convention, not a claim
about letters (Zandbergen, voynich.nu). Benches (ch, sh) and gallows (k, t, p, f) are usually
treated as units. Five scribal hands (Davis 2020). Codicology: Layfield & Davis 2026.

**First moves.** Run `python3 -m vs experiment` on a segmentation with `iin`/`aiin` as units;
compare against `eva-raw`. Look at where ZL and LSI disagree most (`data/raw/LSI_ivtff_0d.txt`).
